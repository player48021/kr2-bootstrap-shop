# Контрольная работа №2 (Войнов М.О., ЭФБО-14-25)

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание
Проект представляет собой учебную версию сайта онлайн-школы английского языка SpeakUp, разработанную с использованием Bootstrap.

## Практическая работа 9
Выполнена главная страница на Bootstrap-сетке.

Реализовано:
- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных курсов;
- подвал страницы.
